# OriginFilter product direction

**Core promise:** user-controlled language and account-country filtering in supported web feeds.

**Default desired preference:** English-language content and US-based accounts. Country origin means the country an account is reported to be based in, not server IP, language, ethnicity or a geotag.

**Targets:** Firefox desktop first, Chrome desktop second, then Android support where technically possible. Instagram web is the primary target, followed by Facebook and X.

**Commercial plan:** free local filters; subscription for maintained country classifications, updates and cross-device preferences. Evaluate opt-in, clearly disclosed sponsorship only after policy review; do not inject covert ads or sell browsing histories.

**Launch gates:** measure classification coverage and accuracy, validate platform adapters, establish commercial data rights, implement privacy/security controls, and confirm store compliance. No guarantee of full country coverage.
