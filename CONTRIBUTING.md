# Contributing to OriginFilter

OriginFilter is an early, independent and **public** browser-extension beta for X, Facebook and YouTube. We welcome reports from real desktop browsers.

To test, see the [v0.8.0 release](https://github.com/rarediary/OriginFilter/releases/tag/v0.8.0) and [beta testing issue](https://github.com/rarediary/OriginFilter/issues/1).

## Bug reports
Use the issue templates and include browser/version, platform, relevant settings and expected/actual behavior. Do not upload passwords, session cookies, access tokens, private messages or sensitive browsing history. Avoid exposing identifiable people when sharing screenshots.

## Development
The canonical shared source is in `extension/`; `firefox/` and `chrome/` are generated by `python tools/build.py`. Run:

```sh
node --test tests/core.test.js tests/ads.test.js tests/practical.test.js
python tools/build.py
```

Optional synthetic browser checks require Chromium and Playwright. Synthetic passes are **not** proof of live authenticated feed compatibility or account-country accuracy.

## Pull requests
Discuss major changes in an issue first. Keep site-specific selectors in the adapters, avoid collecting private user data, treat unknown countries as **unknown**, and do not infer nationality, race, or location from language or appearance. New sponsors must be opt-in, labeled, and comply with browser store policies. Do not add paid hosting dependencies without clearly documented opt-in and no-cost alternatives.
